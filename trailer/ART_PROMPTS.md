# Art to generate for the trailer (ChatGPT image prompts)

How to run them:

- Run each prompt in a new ChatGPT image chat and attach two style references from `trailer/public/` (or the website):
  `art/penny.webp` and `web/captains/rook-character.webp`. Characters then match the Captains.
- "Transparent background" means a PNG with alpha. If ChatGPT returns a white or black background instead, send it anyway
  and I will cut it out.
- Save each image with the file name given and send them all as one zip. They go in `trailer/public/gen/`.

Priority **P1** shots cannot be built without the image. **P2** shots look better with it, and I have a fallback if it
never arrives.
