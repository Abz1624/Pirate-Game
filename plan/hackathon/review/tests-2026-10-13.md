### Headless crash

PlayMode with `-nographics` crashed the Editor (native, `GfxDevice::DrawSharedGeometryJobs` inside
`ScriptableRenderContext.Submit`) from `SnapshotMinimapPresenter.TakeSnapshot` (line 237), called from `LateUpdate`
(line 164). Hackathon code (`741125e3` / `c153ef3f`). Verdict (c), minor: the snapshot render has no guard for
`SystemInfo.graphicsDeviceType == Null`. Any headless run that boots the HUD (batch tests, a `-nographics` server)
crashes. Skip the snapshot when there is no GPU device.
