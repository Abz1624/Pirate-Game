M14 end-of-phase trace set (Windows development player, run once after all M14 code and the review fixes' code
changes except the later pool prewarm counts, which do not touch simulation). Seeds 101/202/303, v3-parity preset,
scripted autopilot, boss forced at 4:00 and killed at 5:00, compared with the V3 goldens (phase-01-config/player).

Before M14 the same set matched V3 exactly (playtest-m10-m13/parity: MATCH on all three). Exact V3 parity ends with
M14 by decision; the set now differs from the first spawn on. Explained differences:

1. Header configHash: expected. Since 14.3 the stage profile is built from the V4 configs (the export equals V3's
   clone except the unused schedule snapshot), so its content hash changes.
2. First divergence, every seed: the first ambient spawn (t = 2.0167 s, same enemy, same time) lands one placement step
   (about 2.5 m in z) away. The only earlier record (the ship at 0.02 s) matches exactly, and the placement settings
   and random stream are unchanged (spawner profiles equal V3's by test). The most likely cause, inferred rather than
   isolated (that would need another trace run), is intended change 4 (one frame driver after the run clock: the spawn
   tick now runs after every order-0 shared component instead of interleaved with them by scene file ID), which
   changes what the screen-edge placement reads in that frame. From that point the runs diverge chaotically (enemy positions steer the
   autopilot, which changes kills, pickups, level-ups and weapon choices).
3. Intended changes 1-3 also change the course once the runs diverge: pickups draw from their own seeded stream
   (offsets and fly delays differ, so XP arrives at different times), new enemy models no longer keep island colliders
   for a frame or toggle /Systems, and chest range is measured to the POI position.

What stays the same (checks on the per-minute statistics below):
- The schedule: spawns in minutes 0-2 are identical in count in all three seeds (35 / 36 / 49); the boss is summoned at
  4:00 in all three; spawn counts per minute afterwards follow the same bands (differences track how many enemies
  are alive, which depends on survival).
- No systematic difficulty shift: V4 survived longer on seeds 101 (647 s vs 407 s) and 303 (779 s vs 497 s) and shorter
  on 202 (250 s vs 364 s, died in the boss fight before killing the boss). Rum follows survival (53 vs 42, 58 vs 52,
  13 vs 42).
