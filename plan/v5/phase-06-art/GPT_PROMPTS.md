# GPT image prompts

One ready-to-paste prompt per art asset in the Art Guide, for ChatGPT image generation. Each prompt stands alone: paste it as is into a new message. The groups go in priority order, so start with the icons that keep content out of the game.

## How to use these prompts

- **Icons** come out as finished art. Ask for a transparent background (each prompt does), download the PNG and check it at 64 px before handing it on. The 1024×1024 master is imported at 256.
- **For a matching style**, attach one existing icon as a reference in the same message, for example `Assets/UI/New_items/Items/Stormglass.png` for items or `Assets/UI/New_items/weapons/Lightning Mast.png` for weapons, and add "match the style of the attached icon". The existing icons are hand-painted cartoon objects with soft cel shading, glossy highlights and no outline.
- **For evolutions**, attach the base weapon's icon and ask for the evolved version of it.
- **3D models** (enemies, pickups, POIs, weapon models, decorations) get one image each: the object alone, in a three-quarter view from above, on a plain background. Your 3D team models from it. The game camera looks down at about 55°, so the top of the model carries its identity.
- **Effect textures** (flames, sparks, rings) are asked for as white or bright shapes on a pure black background, for additive particles. Particle sheets are imported at 256 or 512.
- ChatGPT makes 1024×1024, 1536×1024 or 1024×1536 images. For other sizes (banners, 9-slice panels) generate at the nearest size and crop.
- Fix a failed image with a short follow-up in the same chat ("same icon, the rope thicker, no background") rather than a new prompt.
