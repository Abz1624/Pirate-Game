# 09 — Crews, Events, Cosmetics and Narrative

## Crews

One current Crew/account. Default capacity 30; partner capacity configurable. Roles: leader, up to three officers, members. Membership modes open/application/invite. No shared power, treasury, donation, war, co-op or live chat at launch. Moderate names, tags, emblem and announcement.

An active Crew event locks all current members. Joining an active-event Crew shows and accepts its exact unlock time. A player may queue/cancel `Leave when event ends`. At boundary atomically: close competition and unlock, process queued departures/leadership fallback, then apply any next event lock. Review and prize delivery never prolong lock. Reject overlapping locking events.

## Rankings/events

Use best verified single Voyage kill count/account/period. Views: global weekly, Crew daily/weekly, partner daily/weekly, optional Crew aggregate using top ten members. Freeze Crew/event affiliation at run start; first eligible enrolled run fixes campaign representation. Equal kills share rank; time/run ID only orders display. Daily is UTC day; weekly Monday UTC. Complete run must reach server within 24 h after period end; verification can finish later. States: draft, scheduled, active, awaiting submissions, review, finalized, rewarded, archived/cancelled.

Operator publishes immutable rules, eligibility, prizes, ties, cutoff, disqualification and appeal. Allocations use unique event/period/account/prize keys and states pending/approved/delivered/failed/disputed. External payment is outside game; record only private delivery reference.

## Cosmetics

Base rig sockets: hull, sail, flag, emblem, wake, ornament; whole-ship preset fills compatible slots. Cosmetics are stat/collision/visibility neutral, account-bound, persistent after Crew departure and frozen at run start. Inventory supports owned/all, source, collection, favorite, preview, equip, fallback, pagination, restored/refunded/unavailable states. Refund revokes only its entitlement and equips default where required.

## Narrative

Canon: the sea rearranges the archipelago and returns sunk captains ashore; temporary builds disappear while valid permanent rewards remain. Mags explains Ledger/contracts; Crumb provides visual comedy; bosses recur as antagonists. Deliver three skippable opening panels, Zone intro/aftermath, roughly 30 cooldown barks and optional flavor. Never interrupt post-boss survival, gate play or promise real-world earnings. Reuse the cast and game assets for accurately labeled 15–30 second marketing shorts.
