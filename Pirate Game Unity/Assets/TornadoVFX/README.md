# Tornado VFX (Unity 6 · URP · Shuriken · Mobile)

Stylized orange/yellow fantasy tornado. It uses 7 light particle layers, **about 28 live particles**, 1 shader, 6 shared materials and 3 small R8 textures.
The prefab is generated by code, so you can rebuild it at any time.

## 1. Setup

1. The package lives in `Assets/TornadoVFX/`. URP must be the active pipeline.
2. **Tools → Tornado VFX → Build Prefab** creates:
   - `Assets/TornadoVFX/Tornado_VFX.prefab`
   - `Assets/TornadoVFX/Generated/` (textures, materials, meshes)
3. **Tools → Tornado VFX → Add Pool To Scene** adds a `TornadoVFX_Pool` that already references the prefab.
4. Spawn it from gameplay code:

```csharp
using TornadoFX;
public TornadoVFXPool tornadoPool;

var t = tornadoPool.Spawn(hitPoint, intensity: 1f, duration: 4f); // auto-stops after 4 s, then returns to the pool
t.SetColor(new Color(1f, 0.3f, 0.05f));
tornadoPool.Despawn(t);            // graceful stop (plays the end animation, then returns itself)
tornadoPool.Despawn(t, true);      // hard reset
```

Re-running **Build Prefab** overwrites the prefab and every generated asset. If you tweak particle modules by hand, either copy the tweaks back into `TornadoVFXBuilder.cs` or stop re-running the builder.

## 2. Hierarchy

```
Tornado_VFX            (TornadoVFX controller, scale = Scale)
├── Tornado_Core           mesh particles: funnel shells
├── Tornado_Swirls         mesh particles: 4 helical band variants
├── Tornado_Outer_Ribbons  trails only (Render Mode = None)
├── Tornado_Sparks         stretched billboards (atlas frame 1)
├── Tornado_Debris         billboards, alpha blend (atlas frames 2–3)
├── Tornado_Ground_Vortex  horizontal billboards, polar-UV shader
└── Tornado_Glow           large soft billboards (atlas frame 0)
```

Common settings on every layer:
- Looping on, Play On Awake off, Duration 2.
- Simulation Space Local, Scaling Mode Hierarchy.
- Start Speed 0; motion comes from Velocity over Lifetime.
- No shadows and no probes.
- Custom vertex streams: `Position, Normal, Color, UV, Custom1.xy`.

## 3. Particle settings per layer (v2: refined, about 28 live particles)

The body silhouette does the visual work; every other layer supports it. Rotation values are in rad/s. At runtime the controller sets them from **Rotation Speed** (1.6 rev/s by default) × a per-layer ratio.

Motion hierarchy, slowest to fastest:
- **Core** 0.35× (heavy)
- **Ground** 0.3×
- **Swirls** 1.0×
- **Ribbons** 1.05×
- **Sparks** 0.9×
- **Debris** 1.25× (small pieces move fastest)

| Layer | Max | Rate/s | Lifetime | Typical live | Key settings |
|---|---|---|---|---|---|
| **Core** | 6 | 3 | 1.6–2.0 | 5 | Nearly solid orange shells (30%→55% alpha, 12% additive). Size variance ±3%. Noise 0.05. Rises only 0.1–0.25 m/s. |
| **Swirls** | 5 | 3.2 | 1.1–1.5 | 3–5 | 3 band meshes (low/mid/top) at 1.05× the funnel radius, tilted to follow the wall slope. Size over life 0.96→1.06, rise 0.25–0.5, noise 0.04. |
| **Outer Ribbons** | 6 | 4 | 0.5–0.8 | 2–4 | Thin trails emitted on the funnel surface. Radial velocity 0, so they never fly off. Orange→yellow, no white. |
| **Sparks** | 8 | 6 | 0.6–1.0 | 3–6 | Size 0.04–0.08, warm yellow. Radial −0.15…+0.45, so they mostly climb the wall and rarely drift out. Noise 0.25. |
| **Debris** | 10 | 5.5 | 1.2–1.8 | 5–9 | Ring at 1.3× the base radius. Pulled inward (radial −1.4…−0.9), low rise (0.25–0.7), gravity −0.1. Dark silhouettes. |
| **Ground Vortex** | 2 | 0.6 | 2.4–2.8 | 1–2 | One polar disc about 2.3× the base radius. The streak texture in polar UV gives 3 curved spiralling streaks. Slowly shrinks inward. |
| **Glow** | 2 | 0.7 | 2–2.4 | 1–2 | One soft warm horizontal disc under the base. No column haze, no bloom needed. |

**Total:** about 26–30 live particles; at intensity 1.5 about 45.

### Why the silhouette isn't a cone

`TornadoMeshBuilder.Radius()` defines the profile:
- **Base (h = 0):** full base radius, with a quadratic flare so the bottom spreads out.
- **Waist (h = 0.42):** the narrowest point.
- **Above the waist:** the radius grows toward the top radius (power 1.7), which flares the top.

The funnel wall also gets:
- a small S-bend lean;
- sine wobble around the ring, so no ring is a perfect circle.

Several core shells overlap, and each has a random rotation, size and spin speed, so the surface never looks rigid.

## 4. Material / shader

`TornadoFX/StylizedParticle` is one unlit URP shader shared by every layer. It uses:
- premultiplied blending (`Blend One OneMinusSrcAlpha`), plus an **Additive** slider (1 = additive, 0 = alpha blend);
- **Erosion** from Custom1.x, which gives torn, dissolving edges over each particle's life;
- a random UV offset from Custom1.y;
- a two-tone cel ramp: body colour and a white-hot highlight above a threshold;
- a cheap view-angle **fresnel**: bright silhouette edges and a low-opacity centre on the core;
- **UV scrolling**;
- **Vertical fade**, so the funnel mesh has no hard caps;
- a **polar UV** keyword for the ground swirl, so no extra ring texture is needed.

It does not use a depth texture, grab pass, soft particles or distortion. Those were skipped on purpose for mobile.

| Material | Texture | Blend | Used by |
|---|---|---|---|
| M_Tornado_Body | BodyNoise (tiling 2×1, scroll 0.18/−0.5) | 12% additive, fresnel 0.55, centre opacity 0.6 | Core |
| M_Tornado_Swirl | Streak | additive | Swirls |
| M_Tornado_Trail | Streak | additive | Outer Ribbons (trail material) |
| M_Tornado_Ground | Streak, polar (tiling 3×0.8, twist 1.1) | additive | Ground Vortex |
| M_Tornado_AtlasAdditive | Atlas | additive | Sparks **and** ground Glow (shared) |
| M_Tornado_AtlasAlpha | Atlas | alpha blend | Debris |

Each instance gets its colour, intensity and scroll speed through a **MaterialPropertyBlock**. That means pooled tornadoes can look different without creating material copies.

## 5. Textures (generated, single channel R8, uncompressed)

| Texture | Size | Content |
|---|---|---|
| T_Tornado_BodyNoise | 256×256, repeat, mips | Domain-warped horizontal streaky noise that tiles both ways |
| T_Tornado_Streak | 256×64, repeat | Tapered, torn brush stroke (also the ground streaks) |
| T_Tornado_Atlas | 128×128, 2×2 | glow · spark · rock · leaf |

Total texture memory is about 100 KB. If you replace them with hand-painted art, keep them grayscale masks. Brightness in the mask decides both opacity and where highlights appear.

## 6. Controller (`TornadoVFX`) – Inspector parameters

| Param | Effect |
|---|---|
| tornadoHeight / tornadoBaseRadius / waistRadius / tornadoTopRadius / lean | Rebuild the funnel and swirl meshes at runtime (cached per shape and shared across the pool). Also resize the debris ring, ground vortex and glow. |
| rotationSpeed | Main spin in rev/s (default 1.6). Per-layer ratios: core 0.35, ground 0.3, swirls 1.0, ribbons 1.05, sparks 0.9, debris 1.25. Negative reverses the direction. |
| verticalSpeed | Multiplier on upward velocity and texture scroll. |
| turbulence | Multiplier on every layer's Noise strength. |
| tornadoIntensity | 0 = invisible, 0.5 = medium, 1 = normal, 1.5 = extreme. Scales emission and brightness, and adds turbulence above 1. |
| emissionRate | Global emission multiplier. |
| tornadoColor | Main hue. Highlights are derived from it (warm white). Debris uses a dark version of it. |
| glowIntensity | Brightness of the glow and the ground vortex. |
| sparkAmount / debrisAmount | Emission (and max-particle) multipliers for those layers. |
| lifetime | Multiplier on all particle lifetimes. |
| scale | Uniform root scale. Every layer uses Hierarchy scaling. |
| duration | Seconds at full strength before it stops itself. 0 = runs until `StopTornado()`. |
| startupTime / shutdownTime | Length of the start and end sequences. |

**API:**
- `PlayTornado()`, `StopTornado()`, `StopImmediate()`
- `SetIntensity(float)`, `SetScale(float)`, `SetColor(Color)`, `SetRotationSpeed(float)`, `SetShape(h, base, top)`
- `event Finished` fires when the tornado is done; the pool uses it to take the instance back.

The custom inspector adds Play, Stop and intensity buttons while in Play Mode.

**Start sequence** (normalized over `startupTime`):
1. Ground vortex (0–0.25)
2. Dust (0.1–0.4)
3. Core grows upward from 8% height (0.2–0.8)
4. Glow
5. Swirls (0.45–0.8)
6. Ribbons
7. Sparks (0.6–1.0)

**Stop sequence:**
1. Swirls and ribbons fade out first.
2. Sparks thin out.
3. The core narrows to 35% width and stops emitting.
4. Glow fades.
5. The ground vortex fades last.
6. Emission stops. Particles already in the air keep rising until they die; then `Finished` fires.

## 7. Mobile optimization notes

- About 28 particles and 7 draw calls per tornado (1 per layer; trails are the ribbons' only draw).
- Mesh particles are small: the funnel is 375 verts, a swirl is 58 verts, and there are about 11 of them alive.
- Noise quality is Low with 1 octave on every layer, and there is no collision, no lights and no sub-emitters.
- Overdraw is the main cost. The biggest quads are the two flat ground discs (~9–10 m). The column no longer has big glow quads.
  On low-end devices: set `glowIntensity = 0` and disable the Glow child, or lower `Max Particle Size`.
- Colours stay low-HDR: highlights are at most about 1.7, and the body is plain orange. The effect reads without bloom, and with bloom only the spiral edges glow. If the game uses bloom, keep the threshold ≥ 1.
- Nothing is allocated per frame. While the tornado is fully active, Update only advances a timer.
- Pool: prewarm as many as can be on screen at once. `allowExpand` logs a warning if the pool runs dry.
- If the camera cuts through the tornado, lower the Body material's `Center Opacity` so there's less fill.
